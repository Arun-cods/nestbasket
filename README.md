## 📌 About NestBasket

Across India (Hyderabad, Bengaluru, Delhi NCR, Mumbai, Pune, Chennai, and tier-2 hubs like Suryapet), millions of families order daily essentials from quick-commerce apps like **Blinkit**, **Zepto**, **Swiggy Instamart**, **BigBasket Now**, and **Flipkart Minutes**.

However, dynamic darkstore pricing, stealth surge charges, and variable delivery fees cause Indian families to **overpay by ₹1,500 to ₹3,500 every single month**.

**NestBasket** solves this in 1 tap:
- ⚡ **Real-Time Price Arbitrage**: Instantly compares exact MRP, discounted rates, pack sizes, and delivery times across all quick-commerce platforms.
- 🛒 **Multi-Store Basket Splitter**: Automatically suggests splitting your order (e.g., milk on Zepto, atta on Blinkit) to maximize your total monthly savings.
- 📍 **Hyperlocal Darkstore Locator**: Pinpoints pricing down to your city and locality (e.g., Ameerpet, Hitec City, Koramangala, Indiranagar, Gurugram Cyber Hub).
- 🔒 **Zero-Photo Member Privacy**: Regular shoppers authenticate purely via cellular phone and SMS OTP. Zero camera permissions or member pictures are taken.
- 🛡️ **Private Executive Portal**: Founder console gated with 2-step security (Biometrics for Gopagani Arun + Master Passphrase + PIN).
- 📞 **Direct Customer Problem Desk**: Shoppers can report price mismatches, missing items, or store requests with tickets sent directly to the Founder's desk for 1-on-1 resolution via Call and WhatsApp.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/Arun-cods/nestbasket.git

# Navigate to project folder
cd nestbasket

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:3000/` in your browser.

### Build for Production

```bash
npm run build
```

## 🏗️ Architecture & Security

- **Frontend**: React 18 SPA with Vite and Lucide Icons.
- **Styling**: Tailwind CSS with dark executive styling and emerald shopper UI.
- **SMS Gateway**: Real-time DLT-compliant Indian telecom route (`route=q`) via Fast2SMS.
- **Biometric Isolation**: Client-side HTML5 canvas mesh restricted 100% to Founder Gopagani Arun. Zero member photos captured.
- **SEO & Search Indexing**: Google structured JSON-LD data schema, XML sitemaps, and robots.txt.
